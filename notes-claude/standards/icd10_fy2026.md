# ICD-10-CM Universal Coding Rules

**Standards version:** FY2026 (CMS / NCHS, effective 2025-10-01 through 2026-09-30)
**Last reviewed:** 2026-05-19
**Source:** ICD-10-CM Official Guidelines for Coding and Reporting, FY 2026
**Used by:** CDI Co-Pilot (`cdi-review` skill); future SOAP Validator and E/M Scorer engines will read the same file.

These rules apply to **every outpatient encounter regardless of specialty**. Specialty packs in `specialties/<name>.md` layer additional rules on top of these.

---

## 1. Specificity mandate

**Sec I.B.2; Sec IV.F.** Every diagnosis must be coded to the **highest level of specificity the documentation supports**. ICD-10-CM codes are 3–7 characters. A 3-character code is valid only when no further subdivision exists.

Dimensions to check on every diagnosis:
- Type / etiology
- Acuity (acute / chronic / acute-on-chronic)
- Severity or stage
- Laterality where applicable
- Manifestation or complication
- 7th character where required

**Flag:** any diagnosis stated in general terms when the note contains physical exam, imaging, lab, or procedural detail that supports a more specific code.

---

## 2. Laterality

**Sec I.B.13; Sec I.C.13.a.** ICD-10-CM encodes left, right, bilateral, or unspecified for most conditions. Unspecified-side codes are valid **only** when the documentation is genuinely silent on laterality.

Rules:
- If the side is documented anywhere in the note (HPI, exam, imaging report, procedure note, MA documentation), the code must reflect it.
- If bilateral: assign the bilateral code where one exists; otherwise assign separate codes for each side.
- Unspecified-side codes should be **rare** and explicitly justified.

**Flag:** any diagnosis without laterality when directional language appears anywhere in the note.

---

## 3. First-listed diagnosis (outpatient)

**Sec IV.A; Sec IV.G.** The first-listed diagnosis is the condition **chiefly responsible for the services provided during this encounter**. It is not automatically the most severe or most chronic condition.

- Visit for management of a chronic condition → that condition is first-listed.
- New acute problem driving the visit → first-listed even if chronic conditions are also managed.
- Symptom only (no definitive Dx) → the symptom is first-listed.
- Pain-management encounter → G89.x may be first-listed; underlying condition becomes secondary (see Sec I.C.6.b).
- Routine exam → Z00.0x first-listed; individual conditions secondary.

**Flag:** first-listed diagnosis inconsistent with the reason for visit in Subjective or the primary action in the Plan.

---

## 4. Outpatient uncertain diagnosis rule

**Sec IV.H.** Do **NOT** code diagnoses documented as "probable," "suspected," "questionable," "rule out," "working diagnosis," "possible," or similar uncertainty language as if confirmed. Code the **symptom, sign, or abnormal finding** instead.

This rule is the **opposite** of the inpatient rule (Sec II.H). It applies to every outpatient encounter.

**Flag:** any Assessment line with uncertainty qualifiers treated as a confirmed diagnosis. Auto-elevate to critical — Sec IV.H violation.

---

## 5. Code all coexisting conditions that affect care

**Sec IV.J.** All documented conditions that coexist at the time of the encounter and **require or affect patient care, treatment, or management** must be coded. This is a rule, not a best practice.

Do **not** code conditions previously treated that no longer exist. Use history codes (Z80–Z87) when a historical condition influences current care.

**Flag:** chronic conditions reflected in the Plan (medication, lab monitoring, referral, dose change, patient education) that are absent from the Assessment coding list.

---

## 6. Chronic conditions — code at every visit they are managed

**Sec IV.I.** A chronic condition actively monitored or treated at this visit is coded at this visit. The same chronic condition may appear on every note where it receives attention.

**Flag:** active chronic conditions mentioned in Subjective or addressed in Plan (medication renewal, monitoring, etc.) but absent from the Assessment.

---

## 7. Acute / chronic sequencing

**Sec I.B.8.** When a condition exists in both **acute and chronic forms** with separate codes available, sequence the **acute code first** for the encounter at which the acute presentation is being managed.

For acute-on-chronic exacerbation of a known chronic condition (e.g., acute-on-chronic systolic HF I50.23), use the dedicated combination code when one exists.

**Flag:** acute exacerbation of a known chronic condition coded only with the chronic code when an acute or acute-on-chronic option exists.

---

## 8. Combination codes

**Sec I.B.9.** When ICD-10-CM provides a combination code that fully identifies two diagnoses (or a diagnosis with its complication), using two separate codes is an error. Combination codes appear in the Alphabetic Index under "with" / "in" subterms.

**Flag:** separate codes assigned for conditions that the Alphabetic Index would classify under a single combination code.

---

## 9. "With" / "in" convention

**Sec I.A.15.** The word "with" or "in" in ICD-10-CM code titles or the Alphabetic Index means "associated with" / "due to." The classification **presumes** a causal relationship — no explicit provider linkage is required — unless the documentation clearly states the conditions are unrelated.

Common applications:
- Hypertension **with** heart involvement → I11.x (not I10 + I50)
- Hypertension **with** CKD → I12.x + N18.x stage
- Diabetes **with** neuropathy / nephropathy / retinopathy → single combination code from E08–E13

**Flag:** related conditions coded separately when the "with" convention would yield a more specific combination code.

---

## 10. Symptoms vs. definitive diagnosis

**Sec I.B.4–I.B.6.**
- When a definitive diagnosis has been established, do **not** separately code signs and symptoms routinely associated with it (they are integral to the disease process).
- **Do** separately code signs and symptoms that are **not** routinely associated with the established diagnosis.
- When no definitive diagnosis has been established, code the symptom — do not infer the condition.

**Flag:** symptom codes used alongside an established Dx where the symptom is integral to that Dx; or a Dx asserted when only a symptom is documented.

---

## 11. 7th character requirements

**Sec I.C.13 (musculoskeletal); Sec I.C.19 (injuries / Chapter 19).** Several code categories require a 7th character to be valid. Most commonly:

| Code family | 7th character options |
|---|---|
| Traumatic injuries (Chapter 19, S00–T88) | A = initial encounter (active treatment); D = subsequent (routine healing); G = subsequent (delayed healing); K = subsequent (nonunion); P = subsequent (malunion); S = sequela |
| Pathologic fractures (M80, M84) | Same A/D/G/K/P/S set |
| Open fracture (Chapter 19) | B = initial open fracture, type I/II; C = initial open fracture type IIIA/B/C (Gustilo) |
| Obstetrics (Chapter 15) | Various — episode + fetus identifier |

**Critical interpretation rule:** the 7th character reflects **whether active treatment is occurring**, not whether this is the patient's first visit with this provider. A surgeon seeing a patient for the first time for a fracture still under active treatment → **A**.

**Flag:** fracture or injury code missing the 7th character entirely (invalid code); A used during a routine healing phase; D used during active treatment.

---

## 12. External-cause coding

**Sec I.C.20.** External cause codes (V00–Y99) describe how an injury or health condition happened, where it happened, the patient's activity, and the patient's status. Required when work-relatedness is documented or when the encounter codes a traumatic injury.

Required code set for a work injury:
| Element | Category | Example |
|---|---|---|
| Mechanism | W00–X58 | W19.x (fall), W20.x (struck by object), X50.x (overexertion) |
| Place of occurrence | Y92.x | Industrial / construction site, office, warehouse |
| Activity | Y93.x | Activity-specific |
| Work / employment status | Y99.0 | Civilian activity done for income or pay |

Work-relatedness must be documented **by the provider** — not inferred from billing alone.

**Flag:** work injury coded without external-cause codes; mechanism present but place/activity/status missing; work-relatedness implied by patient only, never confirmed by provider.

---

## 13. Post-procedural complication coding

**Sec I.B.16.** A post-procedural complication must be documented with an **explicit cause-and-effect link** between the procedure and the complication. Do not assume causality.

- Routine post-op follow-up → Z47.x (e.g., Z47.1 for post-joint-replacement follow-up).
- Post-procedural complication (mechanical / infection / dehiscence / etc.) → T80–T88 + condition code.
- Periprosthetic fracture → M97.x.
- Implant complication codes (T84.0x–T84.7x) require organism code if infection.

**Flag:** post-op complication described in Plan/Assessment (pain, loosening, infection) without explicit cause-and-effect documentation or without the corresponding T-code.

---

## 14. Standards drift — when to verify

These rules are **stable** within an ICD-10-CM fiscal year (October 1 → September 30). Each year's release replaces specific sections:
- Sections noted as updated in the FY2026 release have "FY 2026" markers in the official guidelines source PDF.
- When code suggestions are made, the underlying code must exist in FY2026. If you suspect a code from the LLM's training data is from an older revision, prefer the more general code in the same family and surface the gap rather than asserting a specific code that may no longer be valid.

## Quick reference — vague-term escalation

When the note uses one of these terms, surface a specificity flag if the listed details aren't documented:

| Vague term | Required modifiers (typical) |
|---|---|
| "Pain" (any joint) | Site (specific structure); laterality; acute vs. chronic; etiology |
| "Fracture" | Site; laterality; displaced / non-displaced; open / closed; traumatic vs. pathologic; 7th character |
| "Heart failure" | Systolic / diastolic; acute / chronic / acute-on-chronic; EF range |
| "Atrial fibrillation" | Paroxysmal / persistent / long-standing persistent / permanent |
| "Hypertension" | Combination category (I10 / I11 / I12 / I13); controlled vs. uncontrolled if relevant |
| "Diabetes" | Type (1 / 2 / drug-induced / due to underlying); complications; long-term insulin / hypoglycemic Z code |
| "CKD" | Stage (N18.1–N18.6) |
| "Sprain" / "Strain" | Specific ligament / muscle; laterality; 7th character |
| "Tendinitis" / "Tendinopathy" | Specific tendon; laterality; acute vs. chronic |
| "Sepsis" | Organism; source / site; severity |
| "Depression" | Type; severity; episode; remission status if applicable |
