# Notes

Free-form notes that don't fit elsewhere. Forward-looking, low-friction, no schedule attached.

Use this folder for:

- **Analytics opportunities** — what we could measure once data lands.
- **Future improvements / fixes** — ideas captured for later, not yet planned.
- **Investigations** — analysis of existing code or data that informs future work.
- **Anything else** — observations, comparisons, "we should think about X" notes.

Once a note matures into actionable work, promote it to [`../plans/`](../plans/). Once a related plan ships, archive it under [`../archive/`](../archive/).

This is **not** the same as:
- [`../plans/`](../plans/) — in-flight feature designs being implemented now.
- [`../pa-planning/`](../pa-planning/) — Phase 2 product/architecture material.
- [`../archive/`](../archive/) — shipped or historical work.

No naming convention beyond "make the filename describe the topic". One file per topic.
